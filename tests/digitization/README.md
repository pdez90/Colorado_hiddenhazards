Tests for the digitization stage (pipeline/segment.py, parse_block.py and the other parse_*.py, consolidate.py, sic_classifier.py / sic_predict.py, link.py, volumes.py): column cuts and line clustering on synthetic word boxes, ORG anchors / ZIP / house-number / mining-code rules and a synthetic three-column page, the SIC OCR-fix, drop and hazard-flag rules, a golden-count regression on four real volumes from data/ocr with listings the review verified by eye, cross-edition linking, the volume table and a classifier smoke test.
Run from the repository root with `python3 -m pytest tests/digitization` (about 25 s; needs pytest, pandas, numpy, scikit-learn, rapidfuzz). conftest.py builds a temporary workspace with the gazetteer from data/geocoder/zip_city.csv and extracts the OCR pages it needs from data/ocr/dcm_ocr_output.tar.gz.
`DCM_PIPELINE=/path/to/pipeline` runs the same suite against another copy of the code (e.g. a `git show HEAD:pipeline/...` export) to see which tests a change flips; `DCM_KEEP_WS=1` keeps the workspace.
